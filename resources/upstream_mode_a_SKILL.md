# Architectural Modeling — 照片与口述建模

修订：2026-09-10

## 目标与自主权

**帮助用户得到准确、精细化、可继续编辑的建筑模型。** 照片任务以参考中可辨认的建筑事实为依据；口述任务以用户描述、尺寸与设计意图为依据。精细化是统一成果要求，不设置草模、方案、严谨等质量档位。

**本 skill 辅助观察、判断和建模；成果要求必须落实并核验，执行方法与顺序由模型自主选择。** 检查可合并，当前仍有效的结论可复用，但不得遗漏适用要求，也不得将未检查视为通过。“按需”指选择方法和参考资料，不是只有察觉疑点才核验。参考文件不整套加载，不为证明遵守 skill 编写台账或重复检查。

先解决会影响后续工作的形态和空间问题，同时兑现约定的构件、材质与交付要求。以实际模型和图像判断成果，流程完成、尺寸闭合、构件数量不能替代准确性。

## 任务边界与输入判断

沿用已确认的软件、范围、尺寸、材质要求和其他条件；延续与局部修改不重新设置任务。只有缺失信息会实质改变成果时才询问，把关联问题合并。可以确认建筑内部、地下与场景的范围，但不询问质量档位，也不把所有实现选择交给用户。

**默认使用 Rhino MCP 建模并交付 `.3dm`。** 用户明确指定其他软件时遵从其选择；不因 Blender 工具可用、操作方便或 Rhino 连接故障而自行切换。Rhino MCP 不可用时先检查连接与当前文档，无法恢复则说明阻塞；改变建模软件须取得用户明确同意。

- **照片／混合输入**：辨别实体边界、遮挡、阴影、反射，抓住整体比例、定义性轮廓、开口及体块关系。其他照片、平立剖图用于约束它们实际揭示的部分，不机械执行每张图同一套测量。确定主参考图；用户未指定时选能清楚表达主体的一张并说明。
- **口述／尺寸输入**：将描述转成关键尺寸、空间关系和可修改控制。通过实际模型反馈迭代；不强加照片配准或双图证明。明确的新指令更新相应条件，保持其余已确认关系。
- **尺度与推断**：用户给定尺寸可直接作为依据。照片不能独立确定绝对尺度时，取得已知尺度，或确认用户接受暂定尺度／相对比例；不能将其称为实测。次要或不可见部分可依建筑逻辑合理推断，简短标明影响后续修改的假设。影响整体尺寸、拓扑、主要形态或使用关系的重大冲突，应澄清后再做依赖它的工作；其余工作继续推进。

## 成果应当具备什么

| 维度 | 判断依据 |
|---|---|
| 形态与意图 | 整体比例、轮廓变化、主要开口、体块关系和空间组织符合依据。决定辨识度的单个特征也需验证；整体相似不能掩盖局部显著错误。 |
| 尺寸 | 明确尺寸、层数、标高、间距等条件落实到实际几何；分项与总量协调。区分给定、量取与推断，精确小数不代表准确；相互冲突的证据不能简单平均。 |
| 建筑装配 | 按建筑师的逻辑建立空间和构件联系。整栋范围内包含逐层楼板、适用交通联系、支承／接地与屋顶闭合；不强加不适用的核心筒或电梯。内部结构按资料和约定表达，不伪称施工级复原。 |
| 构件精细度 | 在约定范围内落实真实门窗／幕墙分格、框架、主要收口及可辨认细节，具有合理厚度、进退、开口和连接。能影响空间或轮廓的构造用几何表达；微观表面可用合适材质与纹理。 |
| 可编辑性 | 按建筑系统和有意义的构件组织名称、图层／集合；重复件可实例化。关键尺寸、形态和模块有可找到的控制参数／对象，局部修改不需重建整栋。不要求无意义地拆分所有面，也不交付无法分解的整栋合并体。 |
| 材质 | 正确分配玻璃、金属、石材等材质及相应光学、表面属性。落实可辨认和已约定的纹理、真实尺度、方向与映射，记录使用的贴图／程序材质来源；来源不明的外观判断须标明为推断。 |
| 场景 | 兑现约定的道路、铺地、绿化、设施、车辆及周边范围和细度，检查建筑与地形／铺地的关系。远景可以按约定简化，场景丰富度不能补偿主体错误。 |
| 文件与呈现 | 可回读的原生模型、可恢复的控制与资源、可用的保存视图，以及由最终模型实际渲染的主视角和辅助视角图片。具体见交付。 |

## 让验证服务于判断

**主体控制几何形成后、批量展开依赖它的细部与内部构件之前，用主视角和补充视角核对主体形态与主要空间关系。** 根据建筑特点检查比例、定义性轮廓、主要开口及体块关系，不套用固定特征清单。发现影响后续构件的明显错误，先修正再批量展开；不依赖争议几何的工作可继续。重复系统先检查代表性构造，局部修改后只复查受影响的内容。

若同类形态失真在多次局部调整后仍持续出现，重新判断控制方法能否表达资料所显示的变化，必要时更换几何表达，而不是持续堆叠局部补丁。具体方法由建筑特点决定。

新环境或执行通路发生变化时，尽早用少量现有或代表性几何确认文档、接口、材质与出图可用。已验证且未变化的环境直接沿用，不为每次任务另建测试项目；软件细节按需查阅 `TOOLING.md`。

**视角匹配**：辨认参考的投影、垂直校正和裁切特征，包括是否为两点透视。用分布于不同位置和深度的建筑特征核对相机与构图，不只对齐外轮廓。评估几何修改时保持相机稳定；投影确有错误时单独修正并重新核对，不通过调相机掩盖模型差异。交付时复查实际出图与参考的视角一致性，以及保存视图能否恢复相应画面。

**构件与空间关系**：对资料中可辨认、影响轮廓或空间使用的构件，核对位置、数量、截面、标高和连接；检查交通构件的起终点、接地及与相应空间的连通。分别判断是否符合资料、是否构造合理，不能以“合理”替代“有依据”。资料未揭示的部分才作必要推断，不用推断覆盖已知事实。

量化依据应适合资料精度与特征重要性，不设通用像素／百分比合格线。照片任务核对可辨认的建筑事实，区分几何、投影、遮挡与光照；口述任务以用户条件和设计意图为依据。不可见部分不声称得到照片验证。

**独立审核**：使用 subagent 辅助发现判断盲点，优先在主体形态形成、关键装配完成和交付前等有实际成果可检查的时机介入。按疑点和返工风险选择范围，可合并复查，不为凑齐阶段重复审核，也不把影响细化的形态问题留到最后。

主模型负责适用成果要求的完整覆盖；subagent 的专项审核不替代这项责任，未提出问题不代表未检查的部分正确。

任务开始时不默认创建模型审核者；确有资料歧义时可委派独立参考分析。提供明确问题、原始依据和当前成果，让审核者独立指出具体差异及影响。修正后复查相关问题，或以证据回应；不把局部结论扩大为整栋通过。复查可沿用同一审核者，复杂项目最终复核可换新审核者。工具不可用时直接核验并说明独立审核未完成。

## 交付

**最终交付前，对“成果应当具备什么”中的所有适用要求做一次覆盖复核。** 可复用当前仍有效的检查结果，补查遗漏及修改影响的部分，不要求每项单独调用工具或写报告。明确错误须修正，未检查或未解决的内容不得默认通过或声称全部完成。核对实际保存模型、视图与图片的一致性，说明推断和剩余限制。阶段预览标为阶段成果；局部修改只更新受影响内容，不自动重跑全套检查。

- **原生模型**：`.3dm` 或 `.blend`，包括语义组织、可找到的关键控制、材质与可访问／打包的资源。保存后实际回读，核查单位、主要对象、材质和视图，打开即可查看完整主体。临时测试不得覆盖用户原有修改。
- **主视角与辅助视角渲染图**：至少交付两张 PNG／JPG，包含一张主视角和至少一张辅助视角，均由最终交付模型实际渲染。照片任务的主视角匹配主参考的观察方向、投影、画幅比例与主体构图；辅助视角补充主视角难以判断的空间深度、体块关系、屋顶或背面，避免只换裁切或重复同一信息。有对应参考时作可比核对，无对应参考时用于展示空间完整性，不声称已获照片验证。口述任务选取能表达设计意图的主视角和互补视角。主图遮挡或裁切妨碍完整查看时，辅助图须展示完整主体。两类图均保留材质表现，模型中保存各自的命名相机／视图及必要渲染设置；相机参数、白模检查截图或生成式图片均不能替代实际渲染图。
- **简短交接说明**：列出模型、主辅视角渲染图和必要资源的位置，两类图各自的相机／视图名称、主参考、关键参数入口、影响理解的推断和剩余限制。过程台账按实际需要保留，不作为成果完整度的替代指标。
