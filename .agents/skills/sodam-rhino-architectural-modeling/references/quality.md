# Final delivery checks

- Confirm the user's supplied dimensions, levels, openings, roof form, and requested scope against actual saved geometry. Distinguish direct evidence, measured estimates, and inference. A photo alone cannot validate unseen faces or absolute scale.
- Reopen the `.3dm`; confirm expected units, object count, semantic names, layers, material assignments, and overall bounds. Open the companion JSON and identify control values for future changes.
- Render a primary and a complementary view from the saved geometry, inspect both image files, and compare the primary view with the supplied reference when one exists. Default cameras and example materials are not proof of a photo match.
- Check that each deliverable path exists. If a `.blend` is promised, verify Blender produced it and that it opens. Never substitute a generated illustration for a model render.
- State the exact limitations: basic JSON mesh primitives or Blender scene mesh import, Blender source-file retention for parametric changes, no Rhino viewport/commands, no Rhino NURBS or Boolean editing, and any unverified dimensions, hidden geometry, materials, camera match, or structural/permit suitability.
